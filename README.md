Arthur – Agentic AI Assistant

Arthur is a Python-based agentic AI assistant powered by Google Gemini.
It can chat, read emails, send emails, and execute tools using function calling.

Features

Gemini-powered conversational AI
Read Gmail emails (IMAP)
Send emails (SMTP)
Tool execution system (agentic loop)
Chat memory (conversation history)
Multi-API key fallback system
Modular design (easy to extend)

How It Works

User sends input
Gemini processes request
If needed, model calls tools:
email_read()
send_email()
Tool result is sent back to model
Arthur responds to user
